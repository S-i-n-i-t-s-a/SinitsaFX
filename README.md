# S i n i t s a Effects for Reshade
AmbientNight:

A shader that enhances dark environments in the game, making shadows more deeper and cold. A properly configured depth buffer is required for full shader work -> (https://www.martysmods.com/the-depth-buffer/)



FairyColors:

It almost replicates the color grading effect from BloomingHDR by BlueSkyDefender, but without the excess (almost ( ͡° ͜ʖ ͡°) ) and with less FPS loss. It makes some bright colors more warmer and softer.
