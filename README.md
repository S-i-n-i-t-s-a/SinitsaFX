# S i n i t s a Effects for Reshade
AmbientNight:

A shader that enhances dark environments in the game, making shadows more deeper and volumetric. A properly configured depth buffer is required -> (https://www.martysmods.com/the-depth-buffer/)



FairyColors:

It almost replicates the color grading effect from BloomingHDR by BlueSkyDefender, but without the excess (almost ( ͡° ͜ʖ ͡°) ) and with less FPS loss. It makes some bright colors more saturated and softer.

AI was used.
